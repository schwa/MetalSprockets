# Tutorials

Learn MetalSprockets step by step.

## Overview

These tutorials start with a triangle. They end with render graphs that contain many elements. Each tutorial adds to the previous one.

📦 **[Companion Code](https://github.com/schwa/MetalSprocketsTutorials)** — Complete Xcode projects for each tutorial.

## Getting Started

Before you start, make sure that you have:

- macOS 26+ / iOS 26+ / visionOS 26+ on a device that supports Metal 4
- Xcode 26+
