# Tutorials

Learn MetalSprockets step by step.

## Overview

These tutorials start with a triangle and progress to render graphs composed of multiple elements. Each tutorial builds on the previous one.

📦 **[Companion Code](https://github.com/schwa/MetalSprocketsTutorials)** — Complete Xcode projects for each tutorial.

## Getting Started

Before you start, check these requirements:

- macOS 15.5+ / iOS 18.5+ / visionOS 26.0+
- Xcode 26+
